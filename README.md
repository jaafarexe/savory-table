# Savory Table

A restaurant ordering app: menu categories (Starters, Mains, Desserts, Drinks & Elixirs), search and filter, a cart with quantity controls, checkout with an order summary, and a live order-status demo.

## Run locally

Prerequisites: Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Build

`npm run build`
